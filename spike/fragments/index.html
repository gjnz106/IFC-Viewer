IFC Delta → fragments: viability spike

Loads one IFC twice — through raw web-ifc (what the app does today) and through @thatopen/fragments — then checks whether everything Compare depends on survived the conversion. Throwaway diagnostic; not part of the app.

Leave Include all attributes on for the first run. Untick it to see what the importer defaults drop — the difference tells you whether a missing property is a config choice or a format limit. Everything runs locally in this tab; no file is uploaded anywhere.
